## Build commands

```bash
# Rust daemon / CLI
cargo build

# Regenerate the iOS Xcode project after changing project.yml or adding source files
cd ios && xcodegen generate && cd ..

# iOS simulator build (fast, unsigned)
xcodebuild -project ios/Sjbis.xcodeproj -scheme Sjbis \
    -destination 'generic/platform=iOS Simulator' \
    CODE_SIGNING_ALLOWED=NO build

# iOS device deploy (archive + sign + install via devicectl)
./scripts/ios-deploy.sh
./scripts/ios-deploy.sh --sim          # simulator only
./scripts/ios-deploy.sh --device <UDID> # specific device
```

## iOS app

The native iOS app lives in `ios/`. It is a SwiftUI app that acts as a client
to the SJBIS daemon's HTTP API (the same API the web dashboard uses).

- `ios/project.yml` — XcodeGen project definition (committed to git)
- `ios/Sjbis/` — Swift source files
- `ios/Local.xcconfig` — team ID and bundle prefix (NOT committed; copy from `Local.xcconfig.example`)
- `ios/Sjbis.xcodeproj` — generated by `xcodegen generate` (NOT committed)

**Setup (one-time):**
1. `cp ios/Local.xcconfig.example ios/Local.xcconfig`
2. Edit `Local.xcconfig` with your `BUNDLE_PREFIX` and `DEVELOPMENT_TEAM`
3. `cd ios && xcodegen generate`

The iOS app connects to the daemon URL configured in Settings (defaults to
`http://localhost:7878`). On a real device, set this to your daemon's LAN IP.
